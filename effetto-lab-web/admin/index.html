PUBLICACIÓN

Los cambios se guardan directamente.

Al guardar un campo o una tarjeta, el contenido queda actualizado en Supabase. El sitio público comenzará a leer estos datos cuando completemos su integración.

IMPORTANTE

Este panel permite editar contenido e imágenes. No ofrece controles para modificar colores, tipografías, estructura o código.
